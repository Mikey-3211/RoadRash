# Local ROM Import Directory for The House of the Dead 2

Place your legally obtained Sega NAOMI arcade ROM dump (`hotd2.zip`) in this directory or select it via the browser prompt.

### Expected Archive Files:
Inside `hotd2.zip`, the upstream engine (`yunophilia/hotd2-recompiled`) extracts:
1. `epr-21585.ic22` (Program ROM)
2. `mpr-21386.ic1` through `mpr-21405.ic20s` (20 x 8 MB mask ROMs)

### Privacy & Licensing Notice:
- Do NOT commit ROM files or generated game binaries to Git.
- This directory is ignored by Git.
- ROM archives remain strictly local to your machine.
