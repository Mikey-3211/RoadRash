2D RUN AND GUN ARCADE CLASSIC

⚙️ POWERED BY GODOT 4.7 ENGINE (WEB/WASM)

Konami's legendary 1987 arcade run-and-gun shooter. Take control of Bill Rizer and Lance Bean as you fight through the Galuga archipelago against the alien entity Red Falcon. Re-engineered in Godot Engine 4.7 with exact 8-direction aiming, authentic jumping arcs, platform drop-downs, and iconic weapons (Rifle, Machine Gun, Spread Gun, Laser, Flame).

DESKTOP CONTROLS

  • Move & Aim: WASD / Arrow Keys
  • Fire Weapon: J / Z
  • Jump: K / X
  • Drop Through: Down + Jump
  • Pause: P / Esc

MOBILE CONTROLS

  • 8-Way Directional: Virtual Arcade D-Pad
  • Action: Fire (A) & Jump (B)
  • Rapid Fire: Autofire Toggle
  • Screen: Landscape Orientation

ENGINE ARCHITECTURE

Built natively using Godot 4.7 Mono (C# / GDScript). Uses CharacterBody2D with pixel-accurate 60Hz deterministic movement, custom Area2D bullet collision layers, and TileMapLayer collision surfaces. Exports directly to HTML5 WebAssembly + WebGL2 for seamless zero-install playback in the browser.
