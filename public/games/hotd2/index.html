ENGINE COMPILATION & BUILD STATUS

The upstream project (yunophilia/hotd2-recompiled) requires running an Emscripten/Python static recompilation pipeline (tools/recomp.py) on a Linux/WSL workstation with toolchain dependencies to generate the game-specific WASM bundle (hotd2.wasm). The browser interface above is configured to parse NAOMI cart headers, validate the ROM layout, and bind to the compiled WASM runner.
