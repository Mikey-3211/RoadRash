VIRTUA COP 2

3D LIGHTGUN ARCADE SHOOTER

🌐 HOSTED EXTERNALLY AT VCOP2.LOL — INTERNET REQUIRED

Originally created by SEGA AM2 in 1995/1997, Virtua Cop 2 brought police lightgun shooting to 3D polygons. This web build was ported to C++/WebAssembly by developer divyanshkul.

DESKTOP CONTROLS

  • Mouse: Aim crosshairs
  • Left Click: Fire weapon
  • Right Click: Reload cylinder
  • P or Middle Click: Pause / Start
  • ESC: Release mouse capture

MOBILE CONTROLS

  • Orientation: Auto-rotates to Landscape
  • Tap Screen: Aim & fire instantly
  • Reload Button: Dedicated on-screen cylinder refill
  • Fullscreen: Integrated fullscreen control
