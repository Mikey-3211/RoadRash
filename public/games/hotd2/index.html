UPSTREAM WORKSTATION BUILD & DEPLOYMENT NOTICE

This browser player uses the exact frontend architecture from yunophilia/hotd2-recompiled (GPL-2.0). To generate the game's compiled WebAssembly binary (web/game/game.wasm):

  1. Place your legal hotd2.zip in a Linux/WSL environment with Emscripten installed.
  2. Run: runtime/build-web.sh /path/to/hotd2.zip
  3. The build outputs compiled WebAssembly and JavaScript into web/game/.

Per GPL-2.0 and Sega copyright constraints, user ROM dumps and ROM-derived generated C/WASM binaries are kept locally and are not distributed publicly on Git or Vercel.
